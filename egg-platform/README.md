# 蛋速达 · 鸡蛋竞拍撮合平台 API

REST 后端服务，提供养殖场（卖方）、采购商（买方）、平台管理后台三端接口。

## 快速开始

```bash
cd egg-platform
npm install
npm start            # 启动后端，默认监听 :3000
```

启动时若无数据库，会自动 seed：

- **管理员**：`13800000000` / 验证码 `123456`
- **养殖场**：`13800000001`、`13800000002`（已认证 + 已缴 1000 元品质保证金）
- **养殖场**：`13800000003`（资质待审核）
- **采购商**：`13900000001`、`13900000002`、`13900000003`（已缴 200 元竞拍保证金）

所有登录的 OTP 验证码统一为 `123456`。

## 接口概览

| 模块 | 路径前缀 | 说明 |
|------|----------|------|
| 认证 | `/api/auth` | OTP 登录、资质提交 |
| 资源 | `/api/resources` | 发布/列表/详情/修改/取消 |
| 竞拍 | `/api/bids` | 出价、自动出价、我的竞拍 |
| 订单 | `/api/orders` | 拉群、群聊、确认收货、纠纷 |
| 保证金 | `/api/deposits` | 缴纳、退还、状态 |
| 消息 | `/api/messages` | 未读消息、已读 |
| 管理后台 | `/api/admin` | 统计、用户/资源/保证金/纠纷 |

## 核心业务规则（已实现）

- **倒计时延时**：剩余 ≤5 分钟有新出价 → 自动延长 5 分钟，最多延长 3 次
- **加价幅度**：每次加价 ≥ `min_increment`（默认 2 元）
- **保证金**：
  - 养殖场 1000 元品质保证金（认证通过后缴纳）
  - 采购商 200 元竞拍保证金（同一时间仅冻结一笔，竞拍失败/被反超即解冻）
- **流拍**：到点无出价 → 资源状态 `failed`，养殖场可重发
- **拉群**：竞拍结束后采购商或养殖场任一方点 "确认收货群" 即拉群
- **自动确认**：拉群 7 天后未确认 → 系统自动确认收货并释放保证金
- **自动出价**：可设置最高价，被反超时系统自动加价（不超过最高价）

数据库为单文件 SQLite，启动时自动建表。
